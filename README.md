One line, at most 20 words, that works as the slogan for a Solana wallet agent. The entry program writes the slogan to `/output/entry.txt`:

> Your Solana wallet grew hands — it pays, swaps, and keeps watch while you live your life.

The image is simple: a wallet that stops sitting still and starts doing the small jobs for you.
Plain words, no jargon — a newcomer reads it once and knows what the agent does.

## Run it

```sh
node main.ts
```
